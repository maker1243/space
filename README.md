# 🚀 SALVAGE STATION

**우주 쓰레기 정거장** — 협동 생존·경영 디펜스 게임 (2-4인)

낮에는 견인빔으로 우주 쓰레기를 인양해 제련기에서 자원을 정제하고, 밤에는 몰려오는 우주 해적과 유성우로부터 정거장을 사수하세요.

## 🎮 바로 플레이

**GitHub Pages**: https://maker1243.github.io/space/

## ✨ 주요 기능

- 🔐 **로그인/회원가입** — 로컬 저장 + SHA-256 해시
- 🌐 **크로스 디바이스 멀티플레이** — WebRTC(P2P) 방 코드 접속
- 🏥 **8개 직업** — 의사 / 엔지니어 / 자루꾼 / 광부 / 요리사 / 사냥꾼 / 정찰병 / 경비대
- 🏆 **20개 업적** — 사용자별 진행도 저장
- 🏗 **11종 기지 확장 모듈** — 발전기·제련소·온실·레이더·의무실·연구소 등
- 🟦 **무한 격벽 확장** — 정거장 실제로 커지고 HP 증가
- ⚙ **제련기 시스템** — 쓰레기를 흡입 → 갈아서 자원 정제
- 🔥 **리액터(캠프파이어) 유지** — 연료 셀 계속 공급 필수
- 🎨 **어몽어스 스타일** 캐릭터 + 팝컬러 그래픽

## 🖥 로컬 서버 (LAN 멀티플레이)

같은 Wi-Fi의 다른 기기와 함께 플레이:

**Windows**: `서버시작.bat` 더블클릭

**수동**:
```bash
python server.py       # 기본 포트 8080
python server.py 3000  # 다른 포트
```

콘솔에 표시되는 LAN IP (예: `http://192.168.x.x:8080/`)를 친구에게 공유하세요.

## 🛠 기술 스택

- **Vanilla HTML5 / Canvas 2D / JavaScript** — 프레임워크 없음
- **PeerJS** (WebRTC) — P2P 멀티플레이 시그널링
- **SubtleCrypto** (SHA-256) — 비밀번호 해싱
- **localStorage** — 유저 / 진행도 저장
