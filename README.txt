  SALVAGE STATION — 우주 쓰레기 정거장 (협동 디펜스)
═══════════════════════════════════════════════════════════════

혼자 플레이 (Solo)
──────────────────
  salvage_station.html 파일을 더블클릭 → 브라우저에서 열림
  → SOLO 선택 → LAUNCH


친구와 함께 (같은 Wi-Fi / LAN)
────────────────────────────
  1. 호스트 PC에서 서버시작.bat 을 더블클릭
     (Python 3 필요 — python.org 에서 설치)

  2. 콘솔 창에 이런 주소가 뜹니다:
        Open on THIS device:
          http://localhost:8080/salvage_station.html
        Share with OTHER devices on the SAME Wi-Fi / LAN:
          http://192.168.x.x:8080/salvage_station.html

  3. 호스트: 브라우저가 자동으로 열림 → HOST 선택 → 방 코드 확인

  4. 친구: 같은 Wi-Fi에 연결된 폰/노트북 브라우저로 위 IP 주소 접속
     → JOIN 선택 → 방 코드 입력 → 자동 참여

  5. 호스트가 LAUNCH 누르면 함께 게임 시작


포트 변경
─────────
  기본은 8080. 다른 포트로 열려면:
     python server.py 3000


트러블슈팅
──────────
  ▸ 다른 기기에서 접속 안 됨?
    - 같은 Wi-Fi / 공유기에 연결되어 있는지 확인
    - Windows 방화벽에서 Python 허용 (첫 실행 시 팝업)
    - 회사/학교 네트워크는 기기 간 통신을 막을 수 있음

  ▸ Python이 없다는 에러?
    - https://python.org 에서 Python 3 설치
    - 설치 시 "Add Python to PATH" 체크

  ▸ 방 참여 실패?
    - 인터넷 연결 확인 (PeerJS 시그널링 서버 필요)
    - 방 코드를 정확히 입력했는지 확인
